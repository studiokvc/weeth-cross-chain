# 2. Données et mécanismes

Ce dépôt porte le transfert et l’émission cross-chain de weETH via LayerZero. Le parcours suit les lockboxes, les messages, la représentation du token distant, les autorisations et les risques de synchronisation. Ce chapitre isole le mécanisme correspondant dans les contrats et bibliothèques du dépôt : état conservé, appels, contrôles et invariant attendu. Les explications restent documentaires et ne constituent ni un audit ni une garantie de déploiement.
